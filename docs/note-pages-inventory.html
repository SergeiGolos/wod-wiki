1 · The note object & the three families

The app routes through a pure classifier (routeView.ts) that maps each URL to one of 14 PageKind values; the page surface (AppContent.tsx) then mounts the component. Three families of pages render a note object:

FamilyWhat the "note object" is herePages
Notes The stored Note (id, title, type, sourceId, catalog, slug). The source (playground · journal · collection · feed · guides · effort · canvas) drives display rules: which buttons exist, whether it is editable, and how list entries link to it. /notes/:noteId, /journal/:date, /playground/:id, /c/:collection/:workout, /feeds/…, /collections/:slug/:date, canvas corpus pages (/p/*, /c/:slug, /)
Efforts Not a note — a registry object (IEffort: slug, label, aliases, baseAttributes, registrySource: bundled|user) serialized as a YAML-frontmatter note document and edited with the standard note editor under the synthetic id effort/<slug>. A shadow note (sourceId effort) is mirrored into the note store on first save so the library can index it. /efforts (catalog), /e/:slug (detail)
Dashboards Literally a note: a vault note with dashboard: true frontmatter whose body ```query fences are the dashboard widgets. Every widget add/edit/move/remove is a revision-guarded text operation on note.rawContent. A vault note shadows a prebuilt seed of the same slug. /dashboards (explorer), /dashboard/:slug / /d/:slug (view)

2 · Shared chrome

Left sidebar — L1 / L2 / L3

The sidebar shows the static L1 tree from appNavTree.ts; the L2 list is the children of whichever L1 is active for the current pathname (auto-synced in NavContext). L3 is never static — each note page publishes its own "On this page" index at runtime.

L1L2 items (type of link)
HomeSyntax (guide-page links, from seeded canvas routes) · Behaviors (guide pages) · Analytics (guide pages)
LibraryJournal → /journal · Collections → /collections · Feeds → /feeds · Playgrounds → /playgrounds
DashboardDynamic panel (DashboardsNavPanel): Explorer link + list of all dashboards (vault first, then prebuilts) + New dashboard action
EffortsAll Efforts → /efforts + one tag link per discipline (Cardio, Strength, …) → /efforts?q=find:effort{discipline:…}
SessionsDynamic panel (SessionsNavPanel): All Sessions link + recent note pages
SettingsAppearance · System · Queries · Tags …

L3 items (published per page via useNotePageNav → NavContext.setL3Items):

  • Every markdown heading in the note (scroll anchors).
  • One entry per ```time fence — carries a Run secondary action and a result-count badge when results exist.
  • One entry per ```log fence — display-only (badge yes, Run affordance no, #891/#894).
  • Rendered inside the ⋮ ActionsMenu ("On this page") below 2xl; owned by the secondary rail from 2xl up.
Deep link /notes/:noteId matches no L1 isActive predicate, so no L2 zone is expanded there — the sidebar shows L1 items only.

Sticky header (desktop lg+; hidden on mobile)

Every page mounts StickyPageHeader (via JournalPageShell on note pages). Slots:

SlotValues typically shown
titleNote title / date / effort label / item name / dashboard title
subtitleRoute id, "N notes", "Editable dashboard note." / "Prebuilt — read-only until cloned", feed source
titleAccessoryChallenge badge (canvas), Bundled/Custom badge (effort)
actionsPageActions — see below
queryBarWQL composer on stream/explorer pages (the header is the query bar)
subheadere.g. collection workout filter strip

Functions in the header action bar (PageActions, mode-driven):

  • Search opens the command palette / WQL search (Ctrl/Cmd+K).
  • Cast chromecast the page.
  • ⋮ Page options ActionsMenu: secondary nav sections + On this page (L3 index) + Download Markdown.
  • New Reset — playground mode only: create a new playground note / reset current page to the default template.

On mobile the header is hidden; ResponsiveActions relocates the same actions into the navbar pin / thumb dock (FAB opens search; dock sheet hosts the page options; playground's New|Reset still renders).

"Time and log" items

Workout blocks in the note body: ```time = a runnable timer script, ```log = a record-only script. They surface in three places:

  1. L3 index entries (above) — Run secondary on time links only.
  2. InlineCommandBar — floating pill buttons at the top-right of each block, from useScriptBlockCommands(mode). Pages only supply handlers they implement; a log block swaps Log in place of Play and drops Today/Schedule (#891/#894).
  3. ResultListItem rows — logged results under the block: clock time, status icon, title/subtitle; the whole row is a button opening the recorded entry.

Button matrix by page mode (verified in useScriptBlockCommands.tsx):

Page modeButtons on a time blockOn a log block
playgroundPlayLog*ShareTodayScheduleLogShare
journal-activePlayLog*ShareScheduleLogShare
journal-historyShareScheduleShareSchedule
journal-planPlaygroundShareSchedulePlaygroundShareSchedule
collection-readonly (collection · feed · effort · canvas)PlayLog*PlaygroundShareScheduleLogPlaygroundShare

* Log appears only when the page wires an onLog handler. Play/Log semantics: Play starts a runtime (/run/:runtimeId); Log opens the block in record mode; Today appends it to today's journal; Schedule opens a date picker; Playground opens it as a new playground page; Share copies a deep link.

3 · Notes views — one per source

Canonical note — NoteByIdPage

/notes/:noteId

Source-agnostic fallback for every note kind (journal, collection item, playground, feed, effort shadow…). Deliberately plain: source does not change display here.

Data displayed

Note title + note id path; raw markdown body in the editor (read mode default). Loading / "Note not found." states.

L2 (left)

None — pathname lights no L1 zone.

L3

Page index from the note's headings + time/log fences (no result badges wired, no Run on this page).

Time/log buttons

None — no command matrix is mounted on this page.

Sticky header

Values: title = entry title, subtitle = /notes/:noteId. Functions: Edit ↔ Read mode toggle; Back button on missing note. Autosave via content provider on idle/blur in edit mode.

Journal date — JournalDatePage

/journal/:date/journal/:identity → redirect

All journal notes for one date, sorted by createdAt. Journal is the fully-writable source.

Data displayed

Date title + "N notes" subtitle; one editor per note (single note → bare editor, multiple → bordered cards with title headers); multi-note chip nav linking each note; result blocks (query:table) injected when a workout completes.

L2 (left)

Library zone: Journal · Collections · Feeds · Playgrounds.

L3

Per-note index (headings + time fences) with Run secondary and result-count badges; log entries display-only.

Time/log buttons

journal-active matrix: PlayLogShareSchedule. Completion writes a result block + records the session.

Sticky header

Values: title = date, subtitle = "N notes". Functions: Edit toggle (default edit — the opposite of the canonical note); ?autoStart=<runtimeId> boots the FullscreenTimer.

Playground note — PlaygroundNotePage

/playground/:id/playground → mints a new note

Personal sandbox note. IDB-first with bundled fallback; only source with Reset + custom widgets.

Data displayed

Formatted page title; markdown body with custom widget components (run-tip, attention, code-example, syntax-group); per-note results; $CURSOR placement.

L2 (left)

Library zone: Playgrounds highlighted.

L3

Page index with Run secondary + result badges (results wired on this page).

Time/log buttons

playground matrix: PlayLogShareTodaySchedule.

Sticky header

Values: title = playground page title. Functions: New create note · Reset restore default template · Search · Cast · ⋮ menu · Move to journal (promotes the same UUID into the journal, clearing the playground source).

Collection workout — WorkoutEditorPage

/c/:collection/:workout/note/:category/:name (legacy → falls through)

Bundled collection item. Read-first; viewing must not mint a note (seeding off at source, #856).

Data displayed

Workout name title; markdown body; page nav index; sourceNote stamping on journal copies.

L2 (left)

Library zone: Collections highlighted.

L3

Page index (headings + time/log fences) with Run secondary.

Time/log buttons

collection-readonly matrix: PlayLogPlaygroundShareSchedule (+ Add-to-today wired). Run appends to today's journal then auto-starts — except syntax category, which runs in a popup.

Sticky header

Values: title = workout name. Functions: Edit ↔ Read toggle (default read) · Search · Cast · ⋮ menu (incl. Download Markdown).

Feed item — FeedItemPage read-only at source

/feeds/:feedSlug/:feedDate/:feedItem

Feed workouts are immutable at source; local edits survive as a scratch overlay keyed feed/{slug}/{date}/{item}. No seeding on view (#856).

Data displayed

Feed item name title; markdown body; "Feed item not found." fallback.

L2 (left)

Library zone: Feeds highlighted.

L3

Page index with Run secondary.

Time/log buttons

collection-readonly matrix: PlayPlaygroundShareTodaySchedule. Run Now clones into today's journal and auto-starts.

Sticky header

Values: title = item name. Functions: Search · Cast · ⋮ menu (Download Markdown of the feed content).

Collection date index — CollectionDatePage

/collections/:slug/:date

Date-scoped list of collection notes (catalog filter) — links only, no editor.

Data displayed

Date title + collection slug subtitle; list of note title + time links → /notes/:noteId.

L2 (left)

Collections zone.

L3

None.

Time/log buttons

None.

Sticky header

Values: title = date, subtitle = collection slug. Functions: standard PageActions.

Canvas corpus pages — MarkdownCanvasPage / ScrollCanvasPage

/p/*/c/:slug/+ all seeded markdown/canvas/** routes

Note-backed (note id canvas:<route>) but layout is declared by the markdown itself: prose sections + buttons/widgets + a sticky editor/runtime panel per section view block.

Data displayed

Prose column (sections with theme/density); widget heroes (carousel, workouts-list); challenge blocks with badge; quests/chapters/scroll specs; per-section editor or runtime panel resolved through the resolveSource DSL.

L2 (left)

Home zone (guide pillars) or Collections zone for /c/:slug collection READMEs.

L3

With-index variant: "On this page" from page headings.

Time/log buttons

Section command pipelines via collection-readonly mode (Play/Playground/Share/Schedule + view-block buttons).

Sticky header

Values: page title + subtitle; workout filter strip subheader on /c. Functions: PageActions collection-readonly (Search · Cast · ⋮).

4 · Efforts views

Effort catalog — QueriableStreamView (EFFORTS_STREAM_PROFILE)

/efforts
Data displayed

Effort rows from find:effort: label, slug (mono), registrySource, discipline; date-group stream or property-table layout per View settings.

L2 (left)

Efforts zone: All Efforts + per-discipline tag links (Cardio, Strength, …).

L3

None — stream list, no page index.

Time/log buttons

None.

Sticky header

Header-less variant: the header is the WQL query bar. Functions: WQL composer (debounced run, examples, vocabulary chips, field catalog) · New (create effort) · View settings (layout/fields/group-by) · Recent entries menu.

Effort detail — EffortDetailPage

/e/:slug/effort/:slug → redirect/e/new?mode=create

Effort registry object rendered as a note document: YAML frontmatter + markdown body. registrySource is the editability rule — bundled is read-only until first edit auto-clones to <slug>-custom (user tier).

Data displayed

Effort label title; Bundled / Custom source badge; frontmatter rendered as a table (met, discipline, intensityTier, aliases, derivation); markdown body; "Effective Resolution" widget (effective MET with base-delta warning, discipline factor, applied-modifier badges, parent slug) toggled by Show Resolved.

L2 (left)

Efforts zone.

L3

Page index from the effort document (headings + time/log fences).

Time/log buttons

collection-readonly matrix: Play (→ /run/:runtimeId) PlaygroundShareSchedule (schedule clones into the journal, category effort).

Sticky header

Values: title = effort label, accessory = Bundled/Custom badge. Functions: Clone (bundled → editable custom copy) · Back to catalog · Show/Hide Resolved · live editing (debounced save to registry + shadow note) · Search · Cast · ⋮ menu.

5 · Dashboards views

Dashboard explorer — AnalyticsExplorerPage

/dashboards/analytics → redirect/dashboard → redirect
Data displayed

WQL query results in a single WidgetFrame: scalar value, timeseries, bars, or date-grouped find stream; RawPointsTable of matched facts; "Records in this calculation" disclosure with derived find WQL; draft-validity indicator + metric/filter vocabulary chips.

L2 (left)

Dashboard zone (dynamic panel): Explorer + dashboard list + New dashboard.

L3

None.

Time/log buttons

None.

Sticky header

Values: header-less — WQL composer query bar. Functions: Run · Save (opens QueryToDashboardDialog: pick editable dashboard or New → appends widget → navigates to /dashboard/:slug) · Inspect pipeline · Records toggle · Explorer options (weeks range, unit) · example chips.

Dashboard view — DashboardViewPage

/dashboard/:slug/d/:slug

Renders a dashboard note: dashboard: true frontmatter + ```query fences parsed into a responsive 1/2/4-column widget grid. Vault note shadows prebuilt seed of the same slug.

Data displayed

Dashboard title + "Editable dashboard note." / "Prebuilt — read-only until cloned" subtitle; widget frames (title, question, query) of types: tablelistvaluetimeseriesbartopliststacked-bargoal-ringszone-distribution; frontmatter tokens ($name) as token controls; per-widget errors (unknown type, missing token, parse failure); SampleDataPrompt when the event store is empty.

L2 (left)

Dashboard zone; the active dashboard is highlighted in the panel list.

L3

None.

Time/log buttons

None — the analog is the per-widget toolbar in edit mode: editmove up/downresize (1/2/4/full)duplicateremove.

Sticky header

Values: title (from the parsed document), subtitle = editable vs prebuilt. Functions: Edit/Done toggle (vault only) · Add widget (composer: dataset + calculation + visualization + preview) · Range selector · Unit preference · per-widget mutations are revision-guarded note-text ops · prebuilt: read-only inspect + Clone to vault.
