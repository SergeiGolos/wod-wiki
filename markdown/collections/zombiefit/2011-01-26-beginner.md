# WOD 319

## Warm Up
```time
Run 1/4 mile | bike 1 mile | row 250m

(3)
  25m Quadrupedal Movement
  10 Sit Ups
  10 Push Ups
  10 Jumping Pull Ups
```

## WOD

### Étudiant — Beginner
```time
(8) :20 Tabata Air Squats
1:00 Rest
(8) :20 Tabata Box Jumps 12in
1:00 Rest
(8) :20 Tabata 5-Foot Precisions
1:00 Rest
(8) :20 Tabata Jumping Pull Ups
```

## Post
Post total number of repetitions performed to comments.

For the tabata Quadrupedal Movement, use each 20-second period to go as far as possible while performing the quadrupedal movement. Score yourself by tabulating feet traveled while QMing.
