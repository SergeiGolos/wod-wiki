# WOD 332

## Warm Up
```time
Run 1/4 mile | bike 1/2 mile | row 250m

(3)
  50m Quadrupedal Movement
  10 Sit Ups
  10 Jumping Pull Ups
```

May substitute jumping pull ups with push ups if you don't have a pull-up bar.

## WOD

### Étudiant — Beginner


```time
50 Sit Ups
```
