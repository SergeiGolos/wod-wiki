# WOD 165

## Warm Up
```time
Run 1/4 mile | row 250m | bike 2 miles

(5) :60 EMOM
  100m Sprint
```

## WOD

### Traceur — Expert
```time
(8) :20 Tabata
  Quadrupedal Movement*
1:00 Rest
(8) :20 Tabata
  Box Jumps (30in)
1:00 Rest
(8) :20 Tabata
  7ft Precisions
1:00 Rest
(8) :20 Tabata
  L-Sit Pull Ups
```

## Cool Down
Go home and watch some parkour videos.

## Post
Post total number of repetitions performed to comments.

* For the Tabata QM, use each twenty second period to go as far as possible while performing the quadrupedal movement. Score yourself by tabulating feet traveled while QMing.  
** As always, you may sub tuck jumps for box jumps.
