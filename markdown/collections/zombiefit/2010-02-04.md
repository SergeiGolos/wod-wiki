# WOD 82

## Warm Up

```time
Run 1/4 mile | bike 2 miles | row 250m

(3)
  10 Air Squats
  10 Sit Ups
  10 Pull Ups | Push Ups // if no pull-up bar
```

## WOD

### Étudiant — Beginner

```time
(5)
  15 Lunges // alternating feet
  5 Burpees
```

### Avancée — Advanced

```time
(5)
  15 Lunges // alternating feet
  5 Burpee Pull Ups
```

### Traceur — Expert

```time
(5)
  15 Lunges // alternating feet
  10 Burpee Pull Ups
```

## Cool Down

Three 100m sprints with 2 minutes rest between each run.
