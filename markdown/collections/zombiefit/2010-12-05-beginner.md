# WOD 282

## Warm Up
```time
Run 1/4 mile | bike 0.5 miles | row 250m

(3)
  10 Air Squats
  10 Sit Ups
  10 Jumping Pull Ups | Push Ups // if you don’t have a pull-up bar
```

## WOD

### Étudiant — Beginner
3 rounds for time.

```time
(3)
  50m Quadrupedal Movement
  5 Five-Foot Precision Jumps
  10 Dips
```

## Cool Down
25 pull ups (may be dead hang, kipping, jumping | assisted).
