# WOD 416

## Warm Up
```time
Run 1/4 mile | row 250m | bike 2 miles

(3)
  10 Air Squats
  10 Push Ups
  10 Sit Ups
  10 Pull Ups
```

You may substitute jumping pull-ups for regular pull-ups.

## WOD

### Étudiant — Beginner
```time
(8) :20 Tabata
  Air Squats
:60 Rest
(8) :20 Tabata
  Box Jumps 12in
:60 Rest
(8) :20 Tabata
  5-Foot Precisions
:60 Rest
(8) :20 Tabata
  Jumping Pull Ups
```

## Cool Down
Go home and watch some parkour videos.

## Post
Post total number of repetitions performed to comments.

For the tabata Quadrupedal Movement (QM), use each 20-second work period to go as far as possible while performing the quadrupedal movement. Score yourself by tabulating feet traveled while QMing.
