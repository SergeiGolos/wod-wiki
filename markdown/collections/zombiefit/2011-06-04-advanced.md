# WOD 410

## Warm Up
```time
Run 1/4 mile | bike 1/2 mile | row 250m

(3)
  10 Air Squats
  10 Push Ups
  10 Sit Ups
  10 Air Squats
  10 Pull Ups | Jumping Pull Ups // if needed
```

## WOD

### Avancée — Advanced
In as few sets as possible, complete:

```time
50 Push Ups
50 Air Squats
50 Jumping Pull Ups
50 Sit Ups
```

## Cool Down
2x100m sprint
