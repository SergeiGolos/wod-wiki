# ZombieFit

1428 workouts from ZombieFit.org (2009–2020), archived from the Wayback Machine. ZombieFit taught parkour-based fitness through tiered daily WODs. Tiered sessions are split one file per level — `YYYY-MM-DD-beginner|advanced|expert.md` (Étudiant/Avancée/Traceur), each carrying the shared Warm Up and Cool Down plus a `level:` frontmatter property; 26 single-level WODs remain unsplit.

Entries are dated (`YYYY-MM-DD*.md`, frontmatter `date:`) and span October 2009 through April 2020. Programming rotates through for-time, AMRAP, intervals, and max-effort formats, with a movement emphasis on parkour skills (quadrupedal movement, precision jumps), burpees, pull-ups, and bodyweight fundamentals.
