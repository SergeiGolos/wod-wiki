# WOD 349

## Warm Up
```time
Run 1/4 mile | bike 2 miles | row 250m

(3)
  10 Sit Ups
  10 Push Ups
  10 Air Squats
  10 Pull Ups | Handstand Push Ups
```

## WOD

### Avancée — Advanced
```time
60 Dips
60 Six-Foot Precisions
100 Alternating Leg Lunges
1/4 mile Run
```

## Post
Post number of sets to comments.

This WOD is meant to be completed in as few sets as possible, which means you can rest as long as you like between sets (suggested not more than 2 minutes). You do not have to complete the movements in any order — e.g., do 20 dips, then 20 precisions, etc. Try to go to failure on every set.
