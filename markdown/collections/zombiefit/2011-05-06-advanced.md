# WOD 386

## Warm Up
```time
Run 1/4 mile | bike 1/2 mile | row 500m

(3)
  25m Quadrupedal Movement
  10 Push Ups
  10 Sit Ups
  10 Air Squats
  25 Jumping Jacks
```

## WOD

### Avancée — Advanced
```time
(5)
  100m Backwards Run
  25 Push Ups
  25 Air Squats
```

## Cool Down
In as few sets as possible, perform 25 Five-Foot Precisions.

```time
25 Five-Foot Precisions
```
