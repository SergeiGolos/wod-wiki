# WOD 307

## Warm Up
```time
Run 1/4 mile | bike 1/2 miles | row 250m

(3)
  50m Quadrupedal Movement
  10 Air Squats
  10 Sit Ups
  10 Jumping Pull Ups // may sub with Push Ups
```

## WOD

### Traceur — Expert
Max effort every precision. If possible, precision over a gap or to a ledge.

```time
Precision Ladder — 1 Precision the 1st minute, 2 Precisions the 2nd minute, 3 Precisions the 3rd minute, continue as long as able. Use as many sets each minute as needed.
```

## Cool Down
Watch parkour on YouTube. Get some sleep.
