# WOD 592

## Warm Up
```time
Run 1/4 mile | bike 1/2 mile | row 250m

3 rounds
  10 Air Squats
  10 Push Ups
  10 Sit Ups
  10 Air Squats
  10 Pull Ups | Jumping Pull Ups
```

## WOD

### Étudiant — Beginner
Stand in place and mark the spot where your feet are. Then find a spot (either visually or by marking it) approximately 4 feet away. That spot is where you’ll be precisioning to for the above WOD.

```time
:60 Intervals
  1 Precision
  2 Precision
  3 Precision
  4 Precision
  5 Precision
  // Continue adding 1 Precision each minute as long as able; use as many sets per minute as needed
```

## Cool Down
In the smallest number of sets possible, complete 50 push ups and 50 pull ups. (May sub with chin ups, jumping pull ups, | L-sit pull ups depending on your ability level.)

```time
50 Push Ups
50 Pull Ups
```
