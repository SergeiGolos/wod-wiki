# WOD 338

## Warm Up
```time
Run 1/4 mile | bike 1/2 mile | row 250m

(3)
  50m Quadrupedal Movement
  10 Sit Ups
  10 Jumping Pull Ups // may sub with Push Ups if you don't have a pull up bar
```

## WOD

### Traceur — Expert

```time
(21-15-9)
  30 inch Box Jumps
  Push Ups
  Air Squats
  L-Sit Pull Ups
```

If needed, sub box jumps with tuck jumps.
