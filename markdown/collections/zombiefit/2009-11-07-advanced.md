# WOD 17

## Warm Up
```time
Run 1/4 mile | bike 2 miles | row 500m

(3)
  50m Quadrupedal Movement
  10 Air Squats
  10 Sit Ups
  10 Jumping Pull Ups
```

(May sub jumping pull ups with push ups if you don’t have a pull up bar.)

## WOD

### Avancée — Advanced
Complete the following sets, in this order, for time:

```time
15 Pull Ups
1 Handstand Push Up
13 Pull Ups
3 Handstand Push Ups
11 Pull Ups
5 Handstand Push Ups
9 Pull Ups
7 Handstand Push Ups
7 Pull Ups
9 Handstand Push Ups
5 Pull Ups
11 Handstand Push Ups
3 Pull Ups
13 Handstand Push Ups
1 Pull Up
15 Handstand Push Ups
```

## Cool Down
```time
(3)
  100m Forward Quadrupedal Movement
```
