# 2016 CrossFit Games - Event 14 "Rope Chipper"

**Location:** StubHub Center, Carson, California
**Date:** July 24, 2016 (Day 5 - Sunday)

## Description

For time: SkiErg, row, and Assault Bike meters with weighted-handle double-unders between each, finishing with a 90-foot sled pull.

```time
200m SkiErg
50 Double Unders
200m Row
50 Double Unders
0.4mile Assault Bike
50 Double Unders
200m Row
50 Double Unders
200m SkiErg
90ft Sled Pull 310lb
```
