# 2014 CrossFit Games - Event 8 "Sprint Carry"

**Location:** StubHub Center, Carson, California
**Date:** July 26, 2014 (Day 3 - Saturday)

## Description

Three 100-yard sprints, each followed by a 100-yard carry of a progressively heavier object.

```time
100yd Sprint
100yd Cylinder Carry 100lb
100yd Sprint
100yd Sandbag Carry 120lb
100yd Sprint
100yd Cylinder Carry 150lb
```

## Scaling

| Level | Carries |
|-------|---------|
| Men | 100-lb cylinder, 120-lb sandbag, 150-lb cylinder |
| Women | 60-lb cylinder, 80-lb sandbag, 100-lb cylinder |

## Breakdown

- **Modality:** Mixed modal
- **Time Domain:** Sprint
- **Primary Movements:** Sprinting, cylinder carry, sandbag carry
- **Intensity:** Maximum effort

## Collectible Metrics

- **Time:** Total time to complete
