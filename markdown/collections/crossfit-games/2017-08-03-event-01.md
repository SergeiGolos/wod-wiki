# 2017 CrossFit Games - Event 1 "Run Swim Run"

**Location:** Alliant Energy Center, Madison, Wisconsin
**Date:** August 3, 2017 (Day 1 - Thursday)

## Description

Run 1.5 miles from the Alliant Energy Center to Lake Monona, swim 500 meters around a buoy course, then run 1.5 miles back to the finish.

```time
1.5mile Run
500m Swim
1.5mile Run
```

## Breakdown

- **Modality:** Monostructural
- **Time Domain:** Very long, 60-minute cap
- **Primary Movements:** Running, swimming
- **Intensity:** Sustained endurance

## Collectible Metrics

- **Time:** Total time to complete
