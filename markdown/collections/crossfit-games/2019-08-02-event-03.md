# 2019 CrossFit Games - Event 3 "Ruck"

**Location:** Alliant Energy Center, Madison, Wisconsin
**Date:** August 2, 2019 (Day 2 - Friday)

## Description

6,000-meter ruck run in 4 laps of 1,500 meters, adding pack weight each lap.

```time
1500m Ruck Run 20lb
1500m Ruck Run 30lb
1500m Ruck Run 40lb
1500m Ruck Run 50lb
```

## Scaling

| Level | Pack |
|-------|------|
| Men | 20-30-40-50 lb, increasing each lap |
| Women | 20-30-40-50 lb, increasing each lap |

## Breakdown

- **Modality:** Monostructural
- **Time Domain:** Very long, 40-minute cap
- **Primary Movement:** Ruck run
- **Intensity:** High

## Collectible Metrics

- **Time:** Total time to complete
