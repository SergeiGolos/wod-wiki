# 2018 CrossFit Games - Event 7 "Fibonacci"

**Location:** Alliant Energy Center, Madison, Wisconsin
**Date:** August 3, 2018 (Day 2 - Friday)

## Description

5-8-13 reps of parallette handstand push-ups and double kettlebell deadlifts, then an 89-foot overhead kettlebell lunge to the finish. A repeat of the 2017 final event with the women's rep count matched to the men's.

```time
(5-8-13) 
  Handstand Pushups
  Double KB Deadlifts 203lb
  
89ft Overhead Lunge 53lb
```

## Scaling

| Level | Deficit | Deadlift KBs | Lunge KBs |
|-------|---------|--------------|-----------|
| Men | 14 in | 2 x 203 lb | 2 x 53 lb |
| Women | 8 in | 2 x 124 lb | 2 x 35 lb |
