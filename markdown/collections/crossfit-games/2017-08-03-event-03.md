# 2017 CrossFit Games - Event 3 "Amanda .45"

**Location:** Alliant Energy Center, Madison, Wisconsin
**Date:** August 3, 2017 (Day 1 - Thursday)

## Description

13-11-9-7-5 reps for time of ring muscle-ups and squat snatches. A variation of "Amanda," the 2010 Games tribute to athlete Amanda Miller.

```time
(13-11-9-7-5) Muscle Ups / Squat Snatches 135lb
```
