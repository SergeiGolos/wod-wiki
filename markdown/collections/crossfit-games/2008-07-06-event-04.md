# 2008 CrossFit Games - Event 4 "Squat Grace"

**Location:** The Ranch, Aromas, California
**Date:** July 6, 2008 (Day 2 - Sunday)

## Description

Sunday's final event was Squat Grace: 30 squat clean and jerks, with the top 20 starters staggered by their cumulative Saturday times so the overall Games champions finished first.
