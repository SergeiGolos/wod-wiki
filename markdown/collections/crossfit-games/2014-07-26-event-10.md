# 2014 CrossFit Games - Event 10 "Push Pull"

**Location:** StubHub Center, Carson, California
**Date:** July 26, 2014 (Day 3 - Saturday)

## Description

Four rounds of strict deficit handstand push-ups with increasing reps and deficit, alternating with 50-foot sled pulls of increasing weight. No kipping.

```time
7 Deficit Handstand Pushups
50ft Sled Pull
8 Deficit Handstand Pushups
50ft Sled Pull
9 Deficit Handstand Pushups
50ft Sled Pull
10 Deficit Handstand Pushups
50ft Sled Pull
```

## Breakdown

- **Modality:** Mixed modal
- **Time Domain:** Moderate, 11-minute cap
- **Primary Movements:** Deficit handstand push-up, sled pull
- **Intensity:** Very high
- **Skill Level:** Advanced

## Collectible Metrics

- **Time:** Total time to complete
