# 2010 CrossFit Games - Event 4 "Deadlift-Pistol-Double-under"

**Location:** Home Depot Center, Carson, California
**Date:** July 17, 2010 (Day 2 - Saturday)

## Description

A seven-minute couplet-and-sprint grind: seven heavy deadlifts, a sprint across the court, fourteen alternating pistols and twenty-one double-unders before sprinting back, repeated for as many rounds as possible.

```time
7:00 AMRAP
  7 Deadlifts 315lb
  Sprint Across Court
  14 Pistols
  21 Double Unders
  Sprint Back
```
