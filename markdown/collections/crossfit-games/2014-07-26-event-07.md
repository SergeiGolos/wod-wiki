# 2014 CrossFit Games - Event 7 "Muscle-Up Biathlon"

**Location:** StubHub Center, Carson, California
**Date:** July 26, 2014 (Day 3 - Saturday)

## Description

3 rounds of a 400-meter run and ring muscle-ups, biathlon-style: every time an athlete breaks a set of muscle-ups, they run a 200-meter penalty lap before returning to the rings.

```time
400m Run
18 Muscle Ups
400m Run
15 Muscle Ups
400m Run
12 Muscle Ups
```

## Breakdown

- **Modality:** Mixed modal
- **Time Domain:** Moderate, 18-minute cap
- **Primary Movements:** Running, ring muscle-up
- **Intensity:** Very high
- **Skill Level:** Advanced

## Collectible Metrics

- **Time:** Total time to complete
