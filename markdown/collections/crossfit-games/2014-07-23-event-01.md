# 2014 CrossFit Games - Event 1 "The Beach"

**Location:** Hermosa Beach Pier, Hermosa Beach, California
**Date:** July 23, 2014 (Day 1 - Wednesday)

## Description

Three open-water swims totaling 1,000 yards, with kettlebell thrusters and burpees in the sand between them.

```time
250yd Swim
50 KB Thrusters 35lb
30 Burpees
500yd Swim
30 Burpees
50 KB Thrusters 35lb
250yd Swim
```

## Scaling

| Level | Kettlebell Thrusters |
|-------|----------------------|
| Men | 35 lb |
| Women | 24 lb |

## Breakdown

- **Modality:** Mixed modal
- **Time Domain:** Very long
- **Primary Movements:** Swimming, kettlebell thruster, burpee
- **Intensity:** Sustained endurance

## Collectible Metrics

- **Time:** Total time to complete
