# 2018 CrossFit Games - Event 8 "Madison Triplus"

**Location:** Alliant Energy Center, Madison, Wisconsin
**Date:** August 4, 2018 (Day 3 - Saturday)

## Description

Swim 500 meters on Lake Monona, paddle 1,000 meters on a paddleboard, then run 2,000 meters back to the Alliant Energy Center.

```time
500m Swim
1000m Paddle
2000m Run
```

## Breakdown

- **Modality:** Monostructural
- **Time Domain:** Long, 40-minute cap
- **Primary Movements:** Swimming, paddleboarding, running
- **Intensity:** Sustained endurance

## Collectible Metrics

- **Time:** Total time to complete
