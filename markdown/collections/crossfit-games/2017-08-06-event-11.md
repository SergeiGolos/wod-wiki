# 2017 CrossFit Games - Event 11 "Madison Triplet"

**Location:** Alliant Energy Center, Madison, Wisconsin
**Date:** August 6, 2017 (Day 4 - Sunday)

## Description

5 rounds: a 450-meter run outside the stadium, then 7 hay bale clean burpees — lift the sandbag over the hay bale wall, chest to ground, then jump over the wall.

```time
(5)
450m Run
7 Hay Bale Clean Burpees 100lb
```
