# 2016 CrossFit Games - Event 8 "Climbing Snail"

**Location:** StubHub Center, Carson, California
**Date:** July 23, 2016 (Day 4 - Saturday)

## Description

3 rounds: run the berm, climb 2 ropes, push the Snail 40 feet, then climb 2 ropes again — once on the final round. One rope hangs high enough that the first pulls are done without the legs.

```time
(3)
500m Berm Run
2 Rope Ascents
40ft Snail Push
2 Rope Ascents
```

## Breakdown

- **Modality:** Mixed modal
- **Time Domain:** Moderate, 21-minute cap
- **Primary Movements:** Running, rope climb, Snail push
- **Intensity:** Very high
- **Skill Level:** Advanced

## Collectible Metrics

- **Time:** Total time to complete
