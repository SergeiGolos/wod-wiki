# CrossFit Games

72 events from the 2019–2024 CrossFit Games. Entries are dated (`YYYY-MM-DD-event-NN.md`, frontmatter `date:`) — events from the same competition day share a date and sort by event number.

Each event carries its format (for-time, max-weight, max-reps, ladder), scaling tables where applicable, and collectible metrics.
