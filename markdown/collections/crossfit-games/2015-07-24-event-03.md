# 2015 CrossFit Games - Event 3 "Murph"

**Location:** StubHub Center, Carson, California
**Date:** July 24, 2015 (Day 2 - Friday)

## Description

The Hero workout honoring Navy SEAL Lt. Michael P. Murphy, in weighted body armor: 1-mile run, 100 pull-ups, 200 push-ups, 300 squats, and a final 1-mile run. A very hot afternoon caused heat stroke for several athletes.

```time
1mile Run
100 Pullups
200 Pushups
300 Air Squats
1mile Run
```
