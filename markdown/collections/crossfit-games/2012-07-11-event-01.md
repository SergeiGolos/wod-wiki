# 2012 CrossFit Games - Event 1 "Pendleton 1"

**Location:** Marine Corps Base Camp Pendleton, Oceanside, California
**Date:** July 11, 2012 (Day 1 - Wednesday)

## Description

A surprise opener announced two days before the expected start: an approximately 700-meter ocean swim with fins and an 8-kilometer bike across undulating terrain, scored on arrival order at a checkpoint roughly 150 meters into the 11-kilometer run.

```time
700m Swim
8000m Bike
150m Run
```

## Breakdown

- **Modality:** Endurance
- **Time Domain:** Long, no cap (scored by arrival order at the checkpoint; the race continues)
- **Primary Movements:** Ocean swim with fins, biking, running
- **Intensity:** High
- **Skill Level:** Advanced

## Collectible Metrics

- **Time:** Arrival time at the checkpoint
