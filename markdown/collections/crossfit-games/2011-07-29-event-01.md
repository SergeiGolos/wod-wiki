# 2011 CrossFit Games - Event 1 "Beach"

**Location:** Santa Monica Beach at Santa Monica Pier, Santa Monica, California
**Date:** July 29, 2011 (Day 1 - Friday)

## Description

The first swim event in Games history, held away from the main venue: a 210-meter ocean swim, 1,500-meter soft-sand run, 50 chest-to-bar pull-ups, 100 hand-release push-ups, 200 squats, and a final 1,500-meter soft-sand run.

```time
210m Ocean Swim
1500m Soft Sand Run
50 Chest to Bar Pullups
100 Hand Release Pushups
200 Air Squats
1500m Soft Sand Run
```

## Breakdown

- **Modality:** Mixed modal
- **Time Domain:** Very long, no time cap (winners: 33:21 men, 39:04 women)
- **Primary Movements:** Ocean swim, soft-sand run, chest-to-bar pull-up, hand-release push-up, air squat
- **Intensity:** Sustained endurance

## Collectible Metrics

- **Time:** Total time to complete
