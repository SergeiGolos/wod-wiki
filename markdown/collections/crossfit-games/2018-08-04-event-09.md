# 2018 CrossFit Games - Event 9 "Chaos"

**Location:** Alliant Energy Center, Madison, Wisconsin
**Date:** August 4, 2018 (Day 3 - Saturday)

## Description

A six-station chipper where athletes did not know the movements or reps in advance. SkiErg calories, burpees to bar, single-arm dumbbell overhead squats, single-leg squats, box jump-overs, and a heavy tumbler pull.

```time
35cal SkiErg
30 Burpees to Bar
45 Single Arm Overhead Squats 50lb
40 Single Leg Squats
25 Box Jump Overs 42in
110ft Tumbler Pull 400lb
```
