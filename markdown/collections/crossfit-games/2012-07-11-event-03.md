# 2012 CrossFit Games - Event 3 "Obstacle Course"

**Location:** Marine Corps Base Camp Pendleton, Oceanside, California
**Date:** July 11, 2012 (Day 1 - Wednesday)

## Description

A head-to-head race through the Camp Pendleton School of Infantry obstacle course, run as a three-round bracketed tournament of four-athlete heats with wildcard advancement.

```time
Obstacle Course Run
```

## Breakdown

- **Modality:** Endurance
- **Time Domain:** Short, no cap
- **Primary Movements:** Obstacle course running, climbing, vaulting
- **Intensity:** Very high
- **Skill Level:** Advanced

## Collectible Metrics

- **Time:** Total time to complete the course
