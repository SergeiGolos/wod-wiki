# 2017 CrossFit Games - Event 8 "Strongman's Fear"

**Location:** Alliant Energy Center, Madison, Wisconsin
**Date:** August 5, 2017 (Day 3 - Saturday)

## Description

Move a yoke, two farmer's logs, and a sled across the stadium floor in any order: each object goes 60 feet to midfield and then 60 feet to the end, and every return trip is a handstand walk.

```time
60ft Yoke Carry 500lb
60ft Handstand Walk
60ft Farmers Log Carry 200lb
60ft Handstand Walk
60ft Sled Drag 400lb
60ft Yoke Carry 500lb
60ft Handstand Walk
60ft Farmers Log Carry 200lb
60ft Handstand Walk
60ft Sled Drag 400lb
```

## Scaling

| Level | Yoke | Logs | Sled |
|-------|------|------|------|
| Men | 500 lb | 2 x 200 lb | 400 lb |
| Women | 340 lb | 2 x 120 lb | 310 lb |

## Breakdown

- **Modality:** Mixed modal
- **Time Domain:** Moderate, 10-minute cap
- **Primary Movements:** Yoke carry, farmer's carry, sled drag, handstand walk
- **Intensity:** Very high
- **Skill Level:** Advanced

## Collectible Metrics
