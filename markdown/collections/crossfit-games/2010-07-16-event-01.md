# 2010 CrossFit Games - Event 1 "Amanda"

**Location:** Home Depot Center, Carson, California
**Date:** July 16, 2010 (Day 1 - Friday)

## Description

The first event of the first Games at the Home Depot Center, run Friday night under the stadium lights and named in memory of athlete Amanda Miller: 9-7-5 ring muscle-ups and squat snatches against a 12-minute cap.

```time
(9-7-5) Ring Muscle Ups / Squat Snatches 135lb
```

## Scaling

| Level | Muscle Ups | Squat Snatches |
|-------|-----------|----------------|
| Men | Ring muscle-ups | 135 lb |
