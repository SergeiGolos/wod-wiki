# 2019 CrossFit Games - Event 7 "Split Triplet"

**Location:** Alliant Energy Center, Madison, Wisconsin
**Date:** August 3, 2019 (Day 3 - Saturday)

## Description

Pegboard, double-unders, and dumbbell hang work for 5 rounds.

```time
(5)
  1 Pegboard Ascent
  100 Double Unders
  10 DB Hang Split Snatches 80lb

```
