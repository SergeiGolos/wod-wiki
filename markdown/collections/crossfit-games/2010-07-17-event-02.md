# 2010 CrossFit Games - Event 2 "Pyramid Double Helen"

**Location:** Home Depot Center, Carson, California
**Date:** July 17, 2010 (Day 2 - Saturday)

## Description

A three-round descending pyramid of "Helen" triplets: a 1,200-meter run, 63 kettlebell swings, and 36 pull-ups, then 800 meters, 42 swings, and 24 pull-ups, then 400 meters, 21 swings, and 12 pull-ups.

```time
1200m Run
63 Kettlebell Swings 53lb
36 Pullups
800m Run
42 Kettlebell Swings 53lb
24 Pullups
400m Run
21 Kettlebell Swings 53lb
12 Pullups
```

## Scaling

| Level | Kettlebell Swings |
|-------|-------------------|
| Men | 53 lb (1.5 pood) |
| Women | 35 lb (1 pood) |
