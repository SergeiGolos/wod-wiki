# 2015 CrossFit Games - Event 13 "Pedal to the Metal 2"

**Location:** StubHub Center, Carson, California
**Date:** July 26, 2015 (Day 4 - Sunday)

## Description

Parallette handstand push-ups, then the same row and bike as Pedal to the Metal 1, finishing with double kettlebell deadlifts — the bells carried forward after every two lifts.

```time
12 Parallette Handstand Pushups
24cal Row
16cal Assault Bike
8 KB Deadlifts 203lb
```

## Scaling

| Level | Kettlebells |
|-------|-------------|
| Men | 2 x 203 lb |
| Women | 2 x 124 lb |

- **Modality:** Mixed modal
- **Time Domain:** Short, 7-minute cap
- **Primary Movements:** Handstand push-up, row, Assault Bike, kettlebell deadlift
- **Intensity:** Very high
- **Skill Level:** Advanced
