# 2015 CrossFit Games - Event 1 "Pier Paddle"

**Location:** Hermosa Beach Pier, Hermosa Beach, California
**Date:** July 22, 2015 (Day 1 - Wednesday)

## Description

Swim 500 meters around the pier, paddle 1 mile south and 1 mile back on a paddleboard, then swim the pier again to the finish.

```time
500m Swim
2mile Paddle
500m Swim
```

## Breakdown

- **Modality:** Monostructural
- **Time Domain:** Very long, 60-minute cap
- **Primary Movements:** Swimming, paddleboarding
- **Intensity:** Sustained endurance

## Collectible Metrics

- **Time:** Total time to complete
