# 2018 CrossFit Games - Event 13 "Handstand Walk"

**Location:** Alliant Energy Center, Madison, Wisconsin
**Date:** August 5, 2018 (Day 4 - Sunday)

## Description

50 heavy-rope double-unders, then a handstand walk through a series of obstacles: pylon slalom, ramps, stairs, and parallel bars. Each obstacle must be completed without falling.

```time
50 Heavy Rope Double Unders
Handstand Walk
```

## Breakdown

- **Modality:** Gymnastics
- **Time Domain:** Short, 4-minute cap
- **Primary Movements:** Double-under, handstand walk
- **Intensity:** Very high
- **Skill Level:** Advanced

## Collectible Metrics
