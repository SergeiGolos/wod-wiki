# 2012 CrossFit Games - Event 6 "Track Triplet"

**Location:** Home Depot Center Track, Carson, California
**Date:** July 13, 2012 (Day 2 - Friday)

## Description

Starting immediately after the Ball Toss, three rounds of alternating-leg split snatches, bar muscle-ups, and a 400-meter run.

```time
(3)
  8 Alternating Split Snatches 115lb
  7 Bar Muscle Ups
  400m Run
```
