# 2009 CrossFit Games - Event 3 "Sandbag Hill Sprint"

**Location:** The Ranch, Aromas, California
**Date:** July 10, 2009 (Day 1 - Friday)

## Description

A 170-meter sprint up the Ranch hill carrying 35-lb sandbags — two for men, one for women.

```time
170m Sandbag Sprint
```

| Level | Sandbags |

| Women | 1 x 35 lb |
