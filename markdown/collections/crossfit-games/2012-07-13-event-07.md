# 2012 CrossFit Games - Event 7 "MedBall-Handstand Push-up"

**Location:** Home Depot Center Stadium, Carson, California
**Date:** July 13, 2012 (Day 2 - Friday)

## Description

Three rounds of heavy medicine ball cleans, a 100-foot medicine ball carry, parallette handstand push-ups, and another 100-foot carry.

```time
(3)
  8 Medicine Ball Cleans 150lb
  100ft Medicine Ball Carry
  7 Parallette Handstand Push Ups
  100ft Medicine Ball Carry
```
