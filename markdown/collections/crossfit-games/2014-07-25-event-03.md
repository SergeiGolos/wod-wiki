# 2014 CrossFit Games - Event 3 "Triple-3"

**Location:** StubHub Center, Carson, California
**Date:** July 25, 2014 (Day 2 - Friday)

## Description

All athletes in one large heat: 3,000-meter row, 300 double-unders, and a 3-mile run around the StubHub Center.

```time
3000m Row
300 Double Unders
3mile Run
```

## Breakdown

- **Modality:** Monostructural
- **Time Domain:** Very long
- **Primary Movements:** Rowing, double-under, running
- **Intensity:** Sustained endurance

## Collectible Metrics

- **Time:** Total time to complete
