# 2013 CrossFit Games - Event 3 "Row 2"

**Location:** StubHub Center, Carson, California
**Date:** July 24, 2013 (Day 1 - Wednesday)

## Description

The full 21,097-meter half-marathon row, continuing without rest from Row 1. Scored by total time over the whole distance; the Row 1 checkpoint result carries no bearing here.

21097m Row
