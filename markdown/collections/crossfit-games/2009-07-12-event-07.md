# 2009 CrossFit Games - Event 7 "Triplet"

**Location:** The Ranch, Aromas, California
**Date:** July 12, 2009 (Day 3 - Sunday)

## Description

An 8-minute AMRAP triplet of handstand push-ups, kettlebell swings, and GHD sit-ups.

```time
8:00 AMRAP
  4 Handstand Pushups
  8 Kettlebell Swings 32kg
  12 GHD Situps
```
