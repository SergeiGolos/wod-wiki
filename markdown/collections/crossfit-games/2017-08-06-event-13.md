# 2017 CrossFit Games - Event 13 "Fibonacci Final"

**Location:** Alliant Energy Center, Madison, Wisconsin
**Date:** August 6, 2017 (Day 4 - Sunday)

## Description

Final event. Men: 5-8-13 reps of parallette handstand push-ups and 203-lb kettlebell deadlifts, then an 89-foot overhead lunge with 2 kettlebells. Women: a 3-5-8 handstand push-up ladder paired with the 5-8-13 deadlifts, then the lunge. Only one man finished inside the cap.

```time
(5-8-13) Handstand Pushups / KB Deadlifts 203lb
89ft Overhead Lunge 53lb
```
