# 2014 CrossFit Games - Event 9 "Clean Speed Ladder"

**Location:** StubHub Center, Carson, California
**Date:** July 26, 2014 (Day 3 - Saturday)

## Description

Race through progressively heavier squat cleans across three rounds. Quarterfinal: 5 bars, 2-minute cap, top 24 advance. Semifinal: 5 heavier bars, 3-minute cap, top 8 advance. Final: 5 heavier bars, 4-minute cap. Ranked by time in the final round reached or heaviest weight cleaned.
