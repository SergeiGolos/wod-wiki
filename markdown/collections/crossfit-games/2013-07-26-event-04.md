# 2013 CrossFit Games - Event 4 "Burden Run"

**Location:** StubHub Center, Carson, California
**Date:** July 26, 2013 (Day 2 - Friday)

## Description

Run 2.1 miles, flip the Pig 100 yards, carry a log 600 yards, then drag the Iditarod sled 66 yards.

```time
2.1mile Run
100yd Pig Flip
600yd Log Carry
66yd Iditarod Drag
```

## Scaling

| Level | Pig | Log | Sled |
|-------|-----|-----|------|
| Men | 490 lb | 100 lb | 310 lb |
| Women | 310 lb | 70 lb | 220 lb |

## Breakdown

- **Modality:** Mixed modal
- **Time Domain:** Very long, 40-minute cap
- **Primary Movements:** Running, Pig flip, log carry, sled drag
- **Intensity:** Sustained endurance

## Collectible Metrics

- **Time:** Total time to complete
