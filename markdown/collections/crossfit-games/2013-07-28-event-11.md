# 2013 CrossFit Games - Event 11 "The Cinco 1"

**Location:** StubHub Center, Carson, California
**Date:** July 28, 2013 (Day 4 - Sunday)

## Description

Three rounds of deadlifts and weighted pistols per leg, then an 80-foot handstand walk. The Cinco 2 begins one minute after this event's time cap.

```time
(3)
5 Deadlifts 405lb
5 Weighted Pistols Left 53lb
5 Weighted Pistols Right 53lb
80ft Handstand Walk
```
