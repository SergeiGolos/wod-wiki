# 2016 CrossFit Games - Event 5 "Murph"

**Location:** StubHub Center, Carson, California
**Date:** July 22, 2016 (Day 3 - Friday)

## Description

The Hero workout honoring Navy SEAL Lt. Michael P. Murphy: 1-mile run, 5 rounds of pull-ups, push-ups, and squats, then a final 1-mile run, all in a weighted vest.

```time
1mile Run
(5)
20 Pullups
40 Pushups
60 Air Squats
1mile Run
```

## Scaling

| Level | Vest |
|-------|------|
| Men | 20 lb |
| Women | 14 lb |

## Breakdown

- **Modality:** Mixed modal
- **Time Domain:** Very long, 55-minute cap
- **Primary Movements:** Running, pull-up, push-up, air squat
- **Intensity:** Sustained endurance
