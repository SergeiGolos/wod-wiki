# 2018 CrossFit Games - Event 12 "Two-Stroke Pull"

**Location:** Alliant Energy Center, Madison, Wisconsin
**Date:** August 5, 2018 (Day 4 - Sunday)

## Description

5 rounds for time of a 300-meter run, Assault Bike calories, and a 44-foot sled pull, finishing when the sled crosses the line.
