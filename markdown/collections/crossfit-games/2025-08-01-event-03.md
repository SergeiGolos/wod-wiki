# 2025 CrossFit Games - Event 3 "Climbing Couplet"

**Location:** MVP Arena, Albany, New York
**Date:** August 1, 2025 (Day 1 - Friday)

## Description

Pegboard ascents paired with squat clean + front squat complexes in a 4-3-2-1 descending ladder with increasing loads.

```time
4 Pegboard Ascents
4 Squat Clean + Front Squats 235lb
3 Pegboard Ascents
3 Squat Clean + Front Squats 265lb
2 Pegboard Ascents
2 Squat Clean + Front Squats 285lb
1 Pegboard Ascent
1 Squat Clean + Front Squat 305lb
```
