# 2013 CrossFit Games - Event 1 "The Pool"

**Location:** Woollett Aquatic Center, Irvine, California
**Date:** July 24, 2013 (Day 1 - Wednesday)

## Description

A surprise addition two days before the official start, and the first swimming event in Games history: 10 rounds of a 25-yard pool swim, bar muscle-ups, and another 25-yard swim.

```time
(10)
25yd Swim
3 Bar Muscle Ups
25yd Swim
```

## Breakdown

- **Modality:** Mixed modal
- **Time Domain:** Long, 25-minute cap
- **Primary Movements:** Swimming, bar muscle-up
- **Intensity:** Very high
- **Skill Level:** Advanced

## Collectible Metrics

- **Time:** Total time to complete
