# 2012 CrossFit Games - Event 8 "Sprint"

**Location:** Home Depot Center Track, Carson, California
**Date:** July 14, 2012 (Day 3 - Saturday)

## Description

A 300-yard shuttle sprint on the football field — to the 50-yard line and back, then to the 100-yard line and back — followed by an immediate reset for the Rope-Sled.

```time
300yd Shuttle Sprint
```

## Breakdown

- **Modality:** Monostructural sprint
- **Time Domain:** Short, no cap
- **Primary Movements:** Shuttle sprinting
- **Intensity:** Maximal effort

## Collectible Metrics

- **Time:** Total time to complete
