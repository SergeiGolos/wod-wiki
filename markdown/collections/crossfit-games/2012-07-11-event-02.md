# 2012 CrossFit Games - Event 2 "Pendleton 2"

**Location:** Marine Corps Base Camp Pendleton, Oceanside, California
**Date:** July 11, 2012 (Day 1 - Wednesday)

## Description

The second scored segment of the unbroken swim-bike-run race: total time for an approximately 700-meter ocean swim with fins, an 8-kilometer bike including roughly 400 meters of unrideable soft sand, and an 11-kilometer hilly dirt-road run with over 1,400 feet of elevation gain.

```time
700m Swim
8000m Bike
11000m Run
```

## Breakdown

- **Modality:** Endurance
- **Time Domain:** Very long, no cap
- **Primary Movements:** Ocean swim with fins, biking, running
- **Intensity:** High
- **Skill Level:** Advanced

## Collectible Metrics

- **Time:** Total time to complete the swim, bike, and run
