# 2018 CrossFit Games - Event 5 "The Battleground"

**Location:** Alliant Energy Center, Madison, Wisconsin
**Date:** August 3, 2018 (Day 2 - Friday)

## Description

For time in a weighted vest: drag the Rescue Randy mannequin across the stadium, climb 2 ropes (one skinny, one fat), run an 8-obstacle course outside the stadium, then return for 2 more rope climbs and the final drag.

```time
Rescue Randy Drag
2 Rope Climbs
Obstacle Course Run
2 Rope Climbs
Rescue Randy Drag
```

## Scaling

| Level | Vest |
|-------|------|
| Men | 20 lb |
| Women | 14 lb |

## Breakdown

- **Modality:** Mixed modal
- **Time Domain:** Moderate, 11-minute cap (men) / 12-minute cap (women)
- **Primary Movements:** Sled drag, rope climb, obstacle run
- **Intensity:** Very high
- **Skill Level:** Advanced

## Collectible Metrics

- **Time:** Total time to complete
