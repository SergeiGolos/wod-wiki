# 2013 CrossFit Games - Event 2 "Row 1"

**Location:** StubHub Center, Carson, California
**Date:** July 24, 2013 (Day 1 - Wednesday)

## Description

First half of a half-marathon row: 2,000 meters for time. The race continues straight into Row 2 with no rest — Row 1 is scored at the 2K checkpoint.

```time
2000m Row
```

## Breakdown

- **Modality:** Monostructural
- **Time Domain:** Moderate
- **Primary Movement:** Rowing
- **Intensity:** Very high

## Collectible Metrics

- **Time:** Time at the 2,000-meter checkpoint
