# The Stone Circle

**Category**: Power Endurance & Density  
**Type**: Sandbag / Progressive EMOM / Minimalist  
**Difficulty**: Intermediate to Advanced

---

## Overview

The Stone Circle is a sandbag strength-and-conditioning protocol built on one idea: **power endurance** — usable, repeatable max power under deep fatigue. It combines single-rep explosion with long-duration endurance, and it rejects slow, grinding repetitions outright. Every rep is an explosive throw; every session is a 30-minute density block.

Progression is density-based rather than sets-and-reps-based, delivered through **progressive EMOM** formats:

- **Intervals Method** — dividing the minute into progressively tighter segments (60s → 30s → 20s).
- **Reps-Per-Minute Method** — stacking successive reps at the start of each interval.

The heart of the program is the **Rite of the Wolf**: a 30-minute power-endurance session of controlled explosive throws (ground → lap → chest → back down) with a bodyweight-level sandbag. Supporting 30-minute sessions rotate around it — heavy (Where Bears Walk), medium (Trial of the Mountain Lion), and light loaded-carry (March of the Elk) strength-endurance work — alongside calisthenics ladders, density isolation blocks, and direct core/neck/posterior-chain accessories.

Sessions run either as a 2-days-on / 1-day-off cycle or a 4-day weekly rotation, paired with a daily movement foundation of 10,000–20,000 steps.

## Rank Standards

Progress is tested at **Level 3 of the Rite of the Wolf** (90 explosive reps in 30 minutes). Bag weight is set relative to bodyweight:

| Rank | Test Load |
|---|---|
| Initiate | Bodyweight − 50 lb |
| Fighter | Bodyweight − 25 lb |
| Berserker | Bodyweight |
| Warlord | Bodyweight + 25 lb |

## How to Use This Collection

Each workout file contains:

- Movement explanation and execution cues
- The full progression ladder as whiteboard scripts (Levels 1.0 → 3)
- Load selection guidance and rank standards
- Progression rules and collectible metrics

Start at Level 1.0 and earn each rung: advance only when you complete all 30 minutes with crisp, explosive reps in every segment. There is no shortcut through the circle — density is the teacher.

## Collectible Metrics

- **Total reps**: Per session and per segment speed (60s / 30s / 20s)
- **Bag weight**: Logged per session against the rank-standard ladder
- **Segments completed**: How far into a rung you stayed explosive before form degraded
- **Rung progression**: Current level.variant held for a full 30-minute session
