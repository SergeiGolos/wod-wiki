# Raffensperger 400m — Week 7 Monday: Race Pace 300s

## Workout

```time
3 x 300m Run @ :52
*2:00 Rest

2 x 200m Run @ :31
*1:30 Rest

1 x 500m Run
```

## Notes

- Targets are ceilings: source says ":52 or below" and ":31 or below" — hit the time or faster.
- 5min rest between the 300s and the 200s, 3min between the 200s and the 500.
- 10-15 strides up a gradual hill to finish.
- Lifting day.
