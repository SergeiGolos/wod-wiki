# Taper Sprint Sharpening

**Duration**: 60 minutes  
**Phase**: Competition Training (Championship Taper — Week 10–11)  
**Total Volume**: ~2,800 yards  

### Description
Designed for the intermediate phase of championship taper (Weeks 10–11 leading into State Championships or Nationals). Volume is reduced by ~50% from standard in-season loads, but race-pace intensity remains elevated. Extended rest intervals allow complete ATP-CP system replenishment, ensuring maximum power output, stroke turnover, and crisp nervous system activation.

```time
(1) Warmup
  400yd Freestyle
  (4)
    75yd Freestyle
    :20 Rest
  (8)
    50yd Freestyle
    :15 Rest

(4) Main Set Race Pace
  25yd Sprint Freestyle
  :45 Rest
  50yd Sprint Freestyle
  1:30 Rest
  25yd Sprint Freestyle
  :45 Rest

(6) Underwater Power
  25yd Underwater Dolphin Kick
  :40 Rest

(1) Cooldown
  400yd Freestyle
```

### Breakdown
- **Warmup**: 1,100yd progressive activation focusing on distance per stroke (DPS) and feel for the water
- **Main Set Race Pace**: 4 rounds of broken 100 pace work at maximum velocity with generous rest to maintain peak technical form
- **Underwater Power**: 150yd high-velocity dolphin kick work off walls simulating championship breakouts
- **Cooldown**: 400yd easy recovery swim to clear metabolic waste

### Collectible Metrics
- 25yd and 50yd sprint times on target race pace
- Dolphin kick count off the wall
