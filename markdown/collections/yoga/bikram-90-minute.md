# Bikram 90-Minute Class

**Duration**: 90 minutes

### Description
The classic Bikram hot yoga sequence: 26 postures (plus opening pranayama and closing savasana) practiced in a heated room. Each posture is traditionally held for two sets — run this as a follow-along timer, one posture at a time.

Durations below are class segments from a recorded 90-minute class: they include the teacher's instruction and demonstration time, not just the hold itself. Treat them as pacing guidance for a full class run-through, not as pure hold targets.

### Breakdown
- **Standing series** (postures 1–11): ~44 minutes — balance, backbends, and forward compression
- **Floor series** (postures 12–25): ~46 minutes — spine work, hip openers, and final relaxation
