# Twisting Vinyasa Flow — 60 Minutes

**Duration**: 60 minutes

### Description
A 60-minute twisting-focus vinyasa class. Unlike the timed Bikram series, this flow is breath-counted: each pose is held for a number of breaths, so the timer runs as tap-to-advance steps — settle into each pose, breathe, and move on. Only the closing Savasana is timed.

Hold guidance per pose is listed in the breakdown below (minimum breath counts from the class plan).

### Breakdown
- **Opening** (~8 min): Child's Pose, Downward Dog, Forward Fold, Mountain — several deep breaths each
- **Sun Salutation A** (~5 min): 3 rounds, 3 breaths in Downward Dog each round
- **Sun Salutation B** (~10 min): 2 rounds — Chair, open-arm twists, then Low Lunge → Lunge Twist → Crescent → Warrior 2 → Reverse Warrior, each side
- **Twisting series** (~10 min): Prayer Twist (min 3 breaths), Standing Straddle Bend (min 3), Warrior 2 (min 2), Extended Side Angle (min 5), Reverse Warrior
- **Inversion** (~2 min): Crow (5 breaths), Child's Pose (5 breaths)
- **Lunge series** (~10 min): Lunge Twist variations, Revolving Crescent Lunge — both sides, flowing with breath
- **Standing series** (~8 min): Warrior 2, Balancing Half Moon (5 breaths each side)
- **Closing** (~7 min): Sleeping Pigeon (min 5 breaths/side), Cobra (min 3), Bound Locust, Seated Forward Fold (5), Happy Baby (5), Supine Spinal Twist (5/side), Savasana (3 min)
