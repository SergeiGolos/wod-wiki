# WOD 150

## Warm Up

```time
Run 1/4 mile | row 250m | bike 2 miles

(3)
  25m Quadrupedal Movement
  10 Sit Ups
  10 Pull Ups | Jumping Pull Ups
  10 Push Ups
  10 Air Squats
```

## WOD

### Étudiant — Beginner

Perform for time, in as few sets as possible (go to failure on each movement).

```time
50 Jumping Pull Ups
50 Sit Ups
50 Air Squats
50 Push Ups
```

### Avancée — Advanced

Perform for time, in as few sets as possible (go to failure on each movement).

```time
75 Jumping Pull Ups
75 Sit Ups
75 Air Squats
75 Push Ups
```

### Traceur — Expert

Perform for time, in as few sets as possible (go to failure on each movement).

```time
100 Jumping Pull Ups
100 Sit Ups
100 Air Squats
100 Push Ups
```
