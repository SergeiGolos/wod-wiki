# HYROX

The indoor fitness race: 8 × 1 km run plus 8 functional stations on one running clock, for every body. This catalog holds the [race card](/collections/hyrox/race-card) — the standard format, official station weights by division, and age groups from the Season 26/27 rulebook — and a complete public [12-week training program](/collections/hyrox/program-overview) (PureGym), with one note per training day across Weeks 1-12.
