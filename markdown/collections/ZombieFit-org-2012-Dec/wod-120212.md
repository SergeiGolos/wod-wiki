# WOD 751

## Warm Up

```time
Run 1/4 mile | row 250m | bike .5 miles

(3)
  25m Quadrupedal Movement
  5 Burpees
  10 Sit Ups
```

## WOD

### Étudiant — Beginner

In 15 minutes, perform as many rounds as possible of:

```time
15:00 AMRAP
  3 Push Ups
  5 Sit Ups
  7 Air Squats
```

### Avancée — Advanced

In 15 minutes, perform as many rounds as possible of:

```time
15:00 AMRAP
  5 Jumping Pull Ups
  7 Sit Ups
  9 Push Ups
```

### Traceur — Expert

In 20 minutes, perform as many rounds as possible of:

```time
20:00 AMRAP
  5 Pull Ups
  7 Sit Ups
  9 Push Ups
```
