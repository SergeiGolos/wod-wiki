# Wilmot

## Description
Six rounds of 50 squats and 25 ring dips.

```time
(6)
  50 Squats
  25 Ring Dips
```

## Profile
Canadian Forces Pvt. Colin Wilmot, 24, 2nd Battalion, Princess Patricia's Canadian Light Infantry, died July 6, 2008 of wounds from an IED in Panjwaii District, Afghanistan.

## Breakdown
- **Modality:** Bodyweight gymnastics
- **Time Domain:** Long, 20-35 minutes
- **Primary Movements:** Squat, ring dip
- **Intensity:** Grindy; high squat volume inflames the ring dips

## Collectible Metrics

- **Time:** Total time to complete all six rounds
