# Jag

## Description
An 800-meter run bookending 28-rep sets of kettlebell swings, strict pull-ups, and kettlebell clean and jerks.

```time
Run 800m
28 Kettlebell Swings 70lb
28 Strict Pullups
28 Kettlebell Clean and Jerks 70lb
28 Strict Pullups
Run 800m
```

## Scaling

| Level | Kettlebell |
|-------|------------|
| Men | 70 lb |
| Women | 53 lb |

## Profile
U.S. Air Force Senior Airman Mark Forester, 29, 21st Special Tactics Squadron, died September 29, 2010 conducting combat operations in Uruzgan Province, Afghanistan.

## Breakdown
- **Modality:** Monostructural running and kettlebell gymnastics
- **Time Domain:** Long, 25-40 minutes
- **Primary Movements:** Run, kettlebell swing, strict pull-up, kettlebell clean and jerk
- **Intensity:** Grindy; strict pull-up volume is the separator

## Collectible Metrics

- **Time:** Total time to complete the workout
