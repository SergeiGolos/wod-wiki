# Del

## Description
A chipper of burpees and gymnastics movements separated by 400-meter runs carrying a medicine ball.

```time
25 Burpees
Run 400m with 20lb Medicine Ball
25 Weighted Pullups 20lb
Run 400m with 20lb Medicine Ball
25 Handstand Pushups
Run 400m with 20lb Medicine Ball
25 Chest-to-Bar Pullups
Run 400m with 20lb Medicine Ball
25 Burpees
```

## Scaling

| Level | Medicine Ball | Dumbbell |
|-------|---------------|----------|
| Men | 20 lb | 20 lb |
| Women | 14 lb | 15 lb |

## Profile
U.S. Army 1st Lt. Dimitri Del Castillo, 24, 2nd Battalion, 35th Infantry Regiment, died June 25, 2011 in Kunar Province, Afghanistan, from enemy small-arms fire.

## Breakdown
- **Modality:** Gymnastics with weighted running
- **Time Domain:** Long, 30-45 minutes
- **Primary Movements:** Burpee, weighted pull-up, handstand push-up, chest-to-bar pull-up, med-ball run
- **Intensity:** High; the loaded runs gate every gymnastics station

## Collectible Metrics

- **Time:** Total time to complete the chipper
