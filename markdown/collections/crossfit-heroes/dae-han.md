# Dae Han

## Description
Three rounds of an 800-meter run carrying an empty barbell, rope climbs, and thrusters.

```time
(3)
  Run 800m with Barbell
  3 Rope Climbs 15ft
  12 Thrusters 135lb
```

## Scaling

| Level | Rope | Thrusters |
|-------|------|-----------|
| Men | 15 ft | 135 lb |
| Women | 15 ft | 95 lb |

## Profile
U.S. Army Sgt. 1st Class Dae Han Park, 36, 3rd Battalion, 1st Special Forces Group (Airborne), died March 12, 2011 in Wardak Province, Afghanistan, from an IED attack.

## Breakdown
- **Modality:** Monostructural, gymnastics, and barbell
- **Time Domain:** Long, roughly 25-35 minutes
- **Primary Movements:** Loaded 800-meter run (empty 45-lb barbell), rope climb, thruster
- **Intensity:** High; the loaded run is the separator

## Collectible Metrics

- **Time:** Total time to complete all three rounds
