# Andy

## Description
Honors Army Sgt. 1st Class Andrew T. Weathers. In a weight vest, for time: 25 thrusters, 50 box jumps, 75 deadlifts, a 1.5-mile run, then the barbell ladder in reverse.

```time
20lb Weight Vest
25 Thrusters 115lb
50 Box Jumps 24in
75 Deadlifts 115lb
1.5mile Run
75 Deadlifts 115lb
50 Box Jumps 24in
25 Thrusters 115lb
```

## Profile
U.S. Army Sgt. 1st Class Andrew T. Weathers, 30, of DeRidder, Louisiana, died Sept. 30, 2014, at Landstuhl Regional Medical Center in Germany. He was wounded two days earlier in Helmand Province, Afghanistan, when he ran through heavy enemy fire to the rooftop where his team was wounded. First posted on crossfit.com on September 26, 2017.

## Breakdown
- **Modality:** Weightlifting, gymnastics, and monostructural work in a vest
- **Time Domain:** Long — descending-and-returning ladder with a run
- **Primary Movements:** Thrusters, box jumps, deadlifts, 1.5-mile run
- **Intensity:** Very high — 300 barbell reps in a vest
- **Skill Level:** Advanced (vest volume)

## Collectible Metrics
- **Time:** Total time to complete
