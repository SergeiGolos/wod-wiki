# Tiff

## Description
Honors Army Capt. Benjamin David Tiffner. On a 25-minute clock, run 1.5 miles, then AMRAP 11 chest-to-bar pull-ups, 7 hang squat cleans, and 7 push presses in the remaining time.

```time
25:00 AMRAP
  1.5mile Run
  11 Chest-to-bar Pullups
  7 Hang Squat Cleans 155lb
  7 Push Presses 155lb
```

## Scaling

| Sex | Loads |
|-----|-------|
| Men | 155-lb barbell |
| Women | 105-lb barbell |

## Profile
United States Army Capt. Benjamin David Tiffner, 31, of West Virginia, died Nov. 7, 2007, when his vehicle was struck by an improvised-explosive device in Baghdad, Iraq, while he was supporting Operation Iraqi Freedom. First posted on crossfit.com on December 23, 2016.

## Breakdown
- **Modality:** Monostructural and weightlifting
- **Time Domain:** Fixed, 25-minute clock
- **Primary Movements:** 1.5-mile run, chest-to-bar pull-ups, hang squat cleans, push presses
- **Intensity:** High — the run splits the clock in half
- **Skill Level:** Advanced (chest-to-bars and cycling 155 lb)

## Collectible Metrics
- **Reps:** Total rounds and reps completed after the run
