# Pat

## Description
Honors Army Ranger Sgt. Patrick Hawkins. Plate-carry runs bracket 14 rounds of 5 strict pull-ups, 4 burpee box jumps, and 3 cleans.

```time
800m Run 25lb
(14)
  5 Strict Pullups
  4 Burpee Box Jumps 24in
  3 Cleans 185lb
800m Run 25lb
```

## Scaling

| Sex | Loads |
|-----|-------|

| Women | 25-lb plate, 20-inch box, 125-lb cleans |

## Profile
Army Sgt. Patrick Hawkins, 25, of Carlisle, Pennsylvania, was killed on Oct. 6, 2013, while conducting a special operations mission in Kandahar Province, Afghanistan, as part of Operation Enduring Freedom. First posted on crossfit.com on May 29, 2017.

## Breakdown
- **Modality:** Monostructural, gymnastics, and weightlifting
- **Time Domain:** Long — 14 rounds inside two weighted runs
- **Primary Movements:** Plate runs, strict pull-ups, burpee box jumps, cleans
- **Intensity:** Very high — small rounds repeat for volume
- **Skill Level:** Advanced (strict pull-ups under fatigue)
