# Daniel Ray

## Description

Five rounds of double-kettlebell carries and lunges around strict pull-ups, push-ups, squats, and runs, honoring a combat controller.

```time
For time:
(5)
  25ft Double KB Front Rack Lunge 53lb
  9 Strict Pullups
  50ft Double KB Overhead Carry 53lb
  16 Hand Release Pushups
  75ft Double KB Front Rack Carry 53lb
  23 Air Squats
  100ft Double KB Farmers Carry 53lb
  400m Run
// if you have a weight vest or body armor, wear it
// ♀ 35lb kettlebells
```

## Scaling

## Profile

Air Force Senior Airman Daniel Ray Sanchez, 23, of El Paso, Texas, a Bronze Star with Valor recipient and combat controller with the 23rd Special Tactics Squadron, was killed in action Sept. 16, 2010, near Kajran District, Afghanistan, when his team came under fire from an Afghan partner-force insurgent.

## Breakdown

- **Modality:** Strongman, gymnastics, and metabolic conditioning
- **Time Domain:** Long, roughly 30-40 minutes
- **Primary Movements:** Kettlebell lunge and carries, strict pull-up, hand-release push-up, air squat, run
- **Intensity:** Sustained grind
- **Skill Level:** Intermediate (overhead carries)

## Collectible Metrics

- **Time:** Total time to complete all five rounds
