# Lumberjack 20

## Description
Honors the soldiers of the 20th Engineer Battalion at Fort Hood killed in the November 5, 2009 shooting, created by the battalion's Lumberjack CrossFit. Twenty reps of seven movements, each followed by a 400-meter run.

```time
20 Deadlifts 275lb
400m Run
20 KB Swings 70lb
400m Run
20 Overhead Squats 115lb
400m Run
20 Burpees
400m Run
20 Chest to Bar Pull Ups
400m Run
20 Box Jumps 24in
400m Run
20 DB Squat Cleans 45lb
400m Run
```

## Scaling

| Sex | Loads |
|-----|-------|
| Men | 275-lb deadlifts, 70-lb kettlebell, 115-lb overhead squats, 24-inch box, 45-lb dumbbells |
| Women | 185-lb deadlifts, 53-lb kettlebell, 75-lb overhead squats, 20-inch box, 30-lb dumbbells |

## Profile
This workout honors Spc. Frederick Greene, 29; Pfc. Aaron Thomas Nemelka, 19; Pfc. Michael Pearson, 22; and Spc. Kham Xiong, 23 — active CrossFitters of the 20th Engineer Battalion, home to Lumberjack CrossFit, killed along with nine others in the Fort Hood shooting on November 5, 2009. It was posted one month after the attack, with the community asked to donate at cflumberjack.org. Lumberjack 20 was first posted on crossfit.com on December 5, 2009.

## Breakdown
- **Modality:** Barbell, kettlebell, gymnastics, running
- **Time Domain:** Long, typically 25-40 minutes
- **Intensity:** Sustained — every heavy or high-skill set is interrupted by a run
