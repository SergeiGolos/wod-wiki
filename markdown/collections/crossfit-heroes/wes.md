# Wes

## Description
Honors Navy Lt. J. Wesley "Wes" Van Dorn. Plate-carry runs bracket 14 rounds of 5 strict pull-ups, 4 burpee box jumps, and 3 cleans.

```time
800m Run 25lb
(14)
  5 Strict Pullups
  4 Burpee Box Jumps 24in
  3 Cleans 185lb
800m Run 25lb
```

## Scaling

| Sex | Loads |
|-----|-------|
| Men | 25-lb plate, 24-inch box, 185-lb cleans |
| Women | 25-lb plate, 20-inch box, 125-lb cleans |

## Profile
U.S. Navy Lt. J. Wesley "Wes" Van Dorn, 29, of Greensboro, North Carolina, died on Jan. 8, 2014. First posted on crossfit.com on April 15, 2017.

## Breakdown
- **Modality:** Monostructural, gymnastics, and weightlifting
- **Time Domain:** Long — 14 rounds inside two weighted runs
- **Primary Movements:** Plate runs, strict pull-ups, burpee box jumps, cleans
- **Intensity:** Very high — grip and shoulder fatigue accumulate
- **Skill Level:** Advanced (strict pull-ups under fatigue)

## Collectible Metrics
- **Time:** Total time to complete
