# Small

## Description
Three rounds of a 1,000-meter row, 50 burpees, 50 box jumps, and an 800-meter run.

```time
(3)
  Row 1000m
  50 Burpees
  50 Box Jumps 24in
  Run 800m
```

## Scaling

| Level | Box |
|-------|-----|
| Men | 24 in |
| Women | 20 in |

## Profile
U.S. Army Staff Sgt. Marc Small, 29, 1st Battalion, 3rd Special Forces Group, died February 12, 2009 of wounds from an insurgent RPG and small-arms attack in Faramuz, Afghanistan.

## Breakdown
- **Modality:** Monostructural conditioning
- **Time Domain:** Long, 35-50 minutes
- **Primary Movements:** Row, burpee, box jump, run
- **Intensity:** High-volume endurance; pacing is everything

## Collectible Metrics

- **Time:** Total time to complete all three rounds
