# Meadows

## Description
A ring-strength chipper descending from muscle-ups to ring push-ups.

```time
20 Muscleups
25 Inverted Hang Lowers
30 Ring Handstand Pushups
35 Ring Rows
40 Ring Pushups
```

## Profile
U.S. Marine Corps Capt. Joshua S. Meadows, 30, 1st Marine Special Operations Battalion (MARSOC), killed by enemy fire September 5, 2009 in Farah Province, Afghanistan.

## Breakdown
- **Modality:** Pure gymnastics strength
- **Time Domain:** Long, highly variable by ring capacity
- **Primary Movements:** Muscle-up, inverted hang lower (slow, straight body and arms), ring handstand push-up, ring row, ring push-up
- **Intensity:** Maximal strength-endurance on rings; scale to ring proficiency

## Collectible Metrics

- **Time:** Total time to complete the chipper
