# Manion

## Description
Seven rounds of a 400-meter run and 29 back squats.

```time
(7)
  Run 400m
  29 Back Squats 135lb
```

## Scaling

| Level | Back Squats |
|-------|-------------|
| Men | 135 lb |
| Women | 95 lb |

## Profile
1st Lt. Travis Manion, 26, U.S. Marine Corps 1st Reconnaissance Battalion, killed by sniper fire April 29, 2007 while fighting an enemy ambush in Anbar Province, Iraq.

## Breakdown
- **Modality:** Running and barbell
- **Time Domain:** Long, 30-45 minutes
- **Primary Movements:** Run, back squat
- **Intensity:** Grindy; 29 unbroken-capacity squats per round reward even pacing

## Collectible Metrics

- **Time:** Total time to complete all seven rounds
