# Matt

## Profile

Army Chief Warrant Officer Matt Ruffner, 34, an AH-64 Apache pilot with the Pennsylvania National Guard's 28th Combat Aviation Brigade, died April 9, 2013, when his helicopter crashed in Pachir Wa Agam District, Afghanistan. Three rounds of 16-rep deadlifts, hang power cleans, and push presses around an 800-meter run, posted on Veterans Day.

```time
(3)
  16 Deadlifts 275lb
  16 Hang Power Cleans 185lb
  16 Push Presses 135lb
  800m Run
```

## Breakdown

- **Modality:** Weightlifting and monostructural cardio
- **Time Domain:** Moderate-long, no cap
- **Primary Movements:** Deadlift, hang power clean, push press, run
- **Intensity:** High; 48 reps per barbell movement across three rounds
