# Hidalgo

## Description
A two-mile run bookending twenty-rep sets of squat cleans, box jumps, and overhead lunges, with two-minute rests between efforts.

```time
Run 2 miles
2:00 Rest
20 Squat Cleans 135lb
20 Box Jumps 24in
20 Overhead Walking Lunges 45lb
20 Box Jumps 24in
20 Squat Cleans 135lb
2:00 Rest
Run 2 miles
```

## Scaling

| Level | Barbell | Box | Plate |
|-------|---------|-----|-------|
| Men | 135 lb | 24 in | 45 lb |
| Women | 95 lb | 20 in | 25 lb |

## Profile
U.S. Army 1st Lt. Daren M. Hidalgo, 24, 3rd Squadron, 2nd Stryker Cavalry Regiment, died February 20, 2011 in Kandahar Province, Afghanistan, of wounds from an IED attack.

## Breakdown
- **Modality:** Monostructural running and barbell work
- **Time Domain:** Long, roughly 30 minutes including rests
- **Primary Movements:** Run, squat clean, box jump, overhead walking lunge
- **Intensity:** Grindy; a 20-lb vest or body armor is optional as prescribed

## Collectible Metrics

- **Time:** Total time to complete the workout
