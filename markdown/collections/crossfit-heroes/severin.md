# Severin

## Description
Honors Army Sgt. 1st Class Severin Summers, Special Forces soldier killed when his vehicle struck an IED in Qole Gerdsar, Afghanistan, in 2009. Fifty strict pull-ups, 100 hand-release push-ups, and a 5K run — in a weight vest if you have one.

```time
50 Pull Ups
100 Hand Release Pushups
5000m Run
```

## Scaling

| Sex | Loads |
|-----|-------|
| Men | 20-lb weight vest |
| Women | 14-lb weight vest |

## Profile
Army Sgt. 1st Class Severin W. Summers III, 43, of Bentonia, Mississippi, served with the 2nd Battalion, 20th Special Forces Group (Airborne), headquartered in Jackson, Mississippi. He died on August 2, 2009, in Qole Gerdsar, Afghanistan, after his vehicle was struck by a command-wire improvised explosive device. He is survived by his wife, Tammy Fraser, and daughters Jessica, Shelby, and Sarah. Severin was first posted on crossfit.com on September 5, 2010.

## Breakdown
- **Modality:** Strict gymnastics and endurance running
- **Time Domain:** Long, typically 35-50 minutes
- **Intensity:** Steady grind — pull-up capacity spent up front must last through the 5K
