# Luke

## Profile

Marine Staff Sgt. Leon H. Lucas Jr., 32, assigned to the 3rd Battalion, 4th Marine Regiment, died August 1, 2011, of wounds from an enemy grenade attack in Helmand Province, Afghanistan. A long chipper: seven 400-meter runs separating five barbell and gymnastic movements.

```time
For Time:
  400m Run
  15 Clean and Jerks 155lb
  400m Run
  30 Toes-to-Bars
  400m Run
  45 Wall Ball Shots 20lb
  400m Run
  45 Kettlebell Swings 53lb
  400m Run
  30 Ring Dips
  400m Run
  15 Front Rack Lunges 155lb
  400m Run
```

## Scaling

## Breakdown

- **Modality:** Weightlifting, gymnastics, and monostructural cardio
- **Time Domain:** Very long, no cap
- **Primary Movements:** Run, clean and jerk, toes-to-bar, wall-ball shot, kettlebell swing, ring dip, front-rack lunge
- **Intensity:** Moderate-high; pacing across seven runs is decisive

## Collectible Metrics

- **Time:** Total time to complete
