# Klepto

## Description
Four rounds of box jumps, burpees, and squat cleans.

```time
(4)
  27 Box Jumps 24in
  20 Burpees
  11 Squat Cleans 145lb
```

## Scaling

| Level | Box | Squat Cleans |
|-------|-----|--------------|
| Men | 24 in | 145 lb |
| Women | 20 in | 95 lb |

## Profile
U.S. Air Force Maj. David "Klepto" Brodeur, 34, died April 27, 2011 in Kabul, Afghanistan, from gunfire by an Afghan military trainee.

## Breakdown
- **Modality:** Gymnastics and barbell
- **Time Domain:** Moderate, 15-25 minutes
- **Primary Movements:** Box jump, burpee, squat clean
- **Intensity:** High; big burpee and box-jump volumes tax the legs before each clean set

## Collectible Metrics

- **Time:** Total time to complete all four rounds
