# Moore

## Description
A twenty-minute AMRAP of a rope climb, a 400-meter run, and a max-effort set of handstand push-ups.

```time
20:00 AMRAP
  1 Rope Climb 15ft
  Run 400m
  Max Handstand Pushups
```

## Profile
Indianapolis Metropolitan Police Department Officer David S. Moore, 29, died January 26, 2011 from gunshot wounds sustained two days earlier after stopping a stolen vehicle.

## Breakdown
- **Modality:** Gymnastics and monostructural running
- **Time Domain:** Long, 20-minute cap
- **Primary Movements:** Rope climb, run, max-rep handstand push-ups
- **Intensity:** Endurance-paced; handstand push-up capacity erodes across rounds

## Collectible Metrics

- **Reps:** Total rounds and reps completed
