# Griff

## Description
Honors Air Force Staff Sgt. Travis L. Griffin, killed by an IED in Baghdad in 2008. An 800-meter run, 400 meters backward, then both again — running in every direction for time.

```time
800m Run
400m Run backwards
800m Run
400m Run backwards
```

## Profile
Air Force Staff Sgt. Travis L. Griffin, 28, was killed on April 3, 2008, when an IED struck his vehicle in the Rasheed District of Baghdad. He is survived by his son, Elijah. Griff was first posted on crossfit.com on June 9, 2008.

## Breakdown
- **Modality:** Monostructural running
- **Time Domain:** Moderate, typically 8-15 minutes
- **Intensity:** Sustained aerobic — backward running doubles the calf and quad demand

## Collectible Metrics
- **Time:** Total time to complete
