# Wade

## Description

A weighted-vest couplet of strict gymnastics wrapped in 1,200-meter runs.

```time
For time:
1200m Run 20lb Vest
(4)
  12 Strict Pullups
  9 Strict Dips
  6 Strict Handstand Pushups
1200m Run 20lb Vest
```

## Scaling

| Level | Vest | Gymnastics |
|-------|------|------------|
| Men | 20 lb or body armor | Strict as written |
| Women | 20 lb or body armor | Strict as written |

## Profile

Army Spc. Andrew Wade of Antioch, Illinois, a weapons specialist with 1st Battalion, 87th Infantry Regiment, 10th Mountain Division, died March 9, 2011, in Bagram, Afghanistan, during Operation Enduring Freedom.

## Breakdown

- **Modality:** Gymnastics and metabolic conditioning
- **Time Domain:** Moderate, roughly 15-25 minutes
- **Primary Movements:** Run, strict pull-up, strict dip, strict handstand push-up
- **Intensity:** Strict-strength grind
- **Skill Level:** Advanced (strict gymnastics under vest)

## Collectible Metrics

- **Time:** Total time to complete
