# Arrowhead Sprint Program — Overview

**Source:** Clinic deck "Sprint Training: Off Season to Peak Season" by Chris Herriot, head coach at Arrowhead High School (WI) for 17 years and past WISTCA president — published via WIAA/sportngin clinic materials and freely available.

## Season Structure

- **Summer:** speed, agility, and weights.
- **Fall:** acceleration (ACC) development plus sport practice — grass "stress levels" of 60-50-40-30-20-10 with roughly 10s rest between efforts.
- **Winter:** ACC+ with longer sprints and weights — the January off-season block this catalog's day files cover.
- **In-Season:** speed maintenance with modified weights.

## Winter Indoor Sessions (field house)

Time-based sprints for indoor space constraints:

```time
3 x 10s Sprint @ 90%
*5:00 Rest

3 x 15s Sprint @ 90%
*5:00 Rest

2 x 20s Sprint @ 90%
*5:00 Rest
```

- The 20s reps take 5-8min rest.

## Off-Season Drill Menu

- Booms
- Ankle stiffness drills
- Mini-barriers
- Wickets
- Flys 10-30
- Falling starts, chase starts, wall drills

## Off-Season (January) — Cataloged Weeks 1-9

January runs two rotations of the same weekly template (first session Monday or Tuesday, then Wednesday and Friday), all written for the 200/400 group. Day files live here as `week-01-monday.md` through `week-09-friday.md`, Monday/Wednesday/Friday only.

- **Rotation 1 (catalog weeks 1-5 = source weeks 1-5):** Monday acceleration @ 90%, Wednesday hills @ 90%, Friday speed @ 95%. Volume climbs through week 3, then tapers in weeks 4-5 as sprint length grows.
- **Rotation 2 (catalog weeks 6-9):** Monday hills @ 90%, Wednesday speed @ 95%, Friday special endurance. **Numbering disclosure:** the source labels these as its own weeks 1-4; this catalog numbers them 6-9 to keep one continuous progression.
- Day files carry only the track sessions — lifting, plyos, drills, and technique work are summarized in each file's notes.

### In-Season Week (template)

#### Monday — Speed

```time
10m Fly
```

- Drills first; the 10m fly uses a 30m run-up with a 5m shift zone.
- Max-speed 10-20-30 runs; the first 4 weeks swap in a 60m Hill Sprint progression.
- Weight room: Back Squat / Bench Press / DB Chest Supported Row — sets M×3, M×4, MH×3, H×3.

#### Tuesday — Tempo

100/200 group:

```time
4 x 80m Run
*1:30 Rest

2 x 150m Run
*1:30 Rest

4 x 80m Run
*1:30 Rest
```

- 90s between reps, 5min between sets.

200/400 group:

```time
(2)
  4 x 200m Run
  *2:00 Rest
  4 x 200m Run
  *2:00 Rest
```

```time
(2)
  3 x 200m Run
  *2:00 Rest
  3 x 200m Run
  *2:00 Rest
```

```time
200m Run @ :25
*1:30 Rest
200m Run @ :24
*1:30 Rest
200m Run @ :24
*1:30 Rest
```

- 30s between reps and 2min between sets on the set work; the 3 × 200m progression runs :25-:24-:24 with 90s rest.
- Every 4th week becomes extensive tempo.

#### Wednesday — Recovery

Rest for some athletes; jumps/vault technique and make-up lifting for others.

#### Thursday — Special Endurance

By athlete strength:

- 24-second drill (measure and record the distance covered).
- Broken 400:

```time
300m Run @ :40
*30s Rest
100m Run
```

- 2 × 500 (control the first 300, kick the last 100); 2 × 250.
- Weight room: clean complex (RDL, clean pull, high pull, muscle clean, front squat) plus hang cleans and jumps.

#### Friday — Rest or Acceleration Work

- Falling starts, standing starts, hop-hop starts, push-up starts, block starts, short stair sprints.

```time
6 x 30m Acceleration
```

#### Saturday — Race Day

- Race day; limit the number of races per athlete.
