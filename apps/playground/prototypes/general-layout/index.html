WHAT CARRIED OVER FROM THE FRAME

  • Warm-yellow active accent (nav + TOC indicator), blue-black surface ramp, hairline dividers.
  • JetBrains Mono for everything the engine produced: syntax, timers, WQL, metric values. Inter for prose.
  • Metric chips with hue semantics (time blue · volume orange · effort green · rounds violet · load red).
  • The embedded output card — AMRAP header chips, dot-bullet segments, footer chips — promoted from docs example to live runtime component.
  • Sidebar payload is contextual per section, never global; the rail is the only constant chrome.
